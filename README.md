# PayFlow AI: PayPal Smart Invoice & Expense Agent

PayFlow AI is an intelligent invoicing and payment workflow automation agent built for the PayPal AI Hackathon. It combines Python (Flask) backend automation with smart text categorization and instant PayPal Sandbox checkout link generation.

## Features
- **AI Smart Categorization:** Dynamically analyzes project descriptions to tag and categorize invoices (e.g., Software Engineering, UI/UX Design, Digital Marketing).
- **Risk & Compliance Scoring:** Automated verification scoring for transaction safety.
- **PayPal Sandbox Integration:** Instantly generates checkout links pointing directly to the PayPal Sandbox environment.

## Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML5, Bootstrap 5
